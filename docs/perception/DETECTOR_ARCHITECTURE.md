# Detector architecture — Task 006

Implemented: immutable DetectionBatch/Detection/Box values, original FrameIdentity, explicit model and transform fingerprints, semantic taxonomy, optional local model adapters, and Task005 scheduler integration. The default remains NoOp. The Java core has no Python or model dependencies. Model libraries load only when a configured adapter is constructed.

Ultralytics handles YOLO26n, YOLO26s and YOLO11n local checkpoints. RT-DETRv2-R18 uses the Peking University converted safetensors checkpoint through Transformers. Both adapters own all vendor objects; only Python values leave the boundary. Local paths and expected SHA256 are required. Do not load arbitrary PyTorch pickle checkpoints.

YOLO uses explicit square letterboxing with rounded resize dimensions, integer padding and per-axis scale factors. Its private predictor keeps tensor-space boxes until ImageMapping restores all four corners through Task003's composed inverse ImageTransform, including source scaling. This avoids the vendor's ideal-ratio inverse rounding error. RT-DETR's pinned processor restores normalized boxes to the prepared image before the same core inverse. Continuous edge coordinates are preserved; boxes are not silently clipped. The affine fingerprint records dimensions and three basis points; runtime settings and processor configuration are fingerprinted separately.

Configure detector runtime, weights, sha256, input_size, confidence, device, half and threads in LabConfig. Its detector interval controls scheduling independently of video frame rate. Existing identity checks reject outputs from other frames. Wrong output types now fail instead of being silently discarded. SUCCESS_EMPTY means inference completed with no detections; NO_OUTPUT is the no-op case; recoverable OOM is a component error. Unexpected errors fail the session.

Execution is synchronous on the owning pipeline thread. Use one model worker per process: runtime thread settings and the network policy are process-wide. Cancellation and freshness are checked between native operations; native inference cannot be forcibly interrupted safely. Each component records execution overrun relative to its scheduling interval. Mobile integration will need runtime-specific deadline handling, stale-result rejection, resource budgets and a fallback. No mobile implementation is included.

No server inference endpoint, training framework, risk model or camera capture was added. ML packages are optional research dependencies. Offline flags and a Python audit hook block Python network connections before vendor import. This is not an operating-system sandbox and does not constrain arbitrary native code; only trusted artifacts may be loaded. Generic tests never fetch weights. Model cache, local vendor settings and media remain ignored.
