## C. Depth architecture

Frame -> provider -> immutable DepthFrame -> robust region DepthEstimate -> optional
detection/track association. Java remains authoritative for image mapping, calibrated
rays and transform composition. No model classes or tensors leave the runtime boundary.

## D. Relative versus metric

Relative output has NONE units and explicit ordering. Accessing meters is rejected.
Metric output has METERS, an explicit Z/range axis and MODEL_ESTIMATED_METRIC_DEPTH
source. A metric model is not a ranging sensor. No relative-to-meter scale fitting.

## E. DepthFrame

Identity, observation timestamp, representation/range, native-resolution float32 map,
validity mask, optional quality map, model/runtime provenance, Java mapping and process
timing. Buffers are immutable even through caller aliases. Invalid samples are masked,
never replaced with a trusted maximum range. Dense maps are absent from default records.

## F. Models evaluated

Depth Anything V2 Small relative and Small metric outdoor, official converted
checkpoints, CPU FP32. Both ran at short-side targets 266 and 392 on 12 spread frames
and six adjacent frames. Metric3Dv2 Small and FastDepth were investigated but not run.
No claim that two checkpoints of one family provide independent model diversity.

## H. Preprocessing

Pinned DPT processor, RGB normalization, aspect-preserving multiple-of-14 resize.
Actual native output dimensions feed Guardian's exact mapping. No full-camera-map
upsampling. Original-camera continuous edge coordinates remain the sampling authority.
Synthetic resize/crop/edge/bilinear tests pass. Padded processor configurations rejected.

## I. Native/ONNX parity

Relative Small exported to a fixed 1x3x266x574 ONNX graph. One real frame passed
rtol=0.001 and atol=0.001, maximum absolute difference 0.00026989, mean 0.000001404,
equal finite masks. Percentiles agree within tolerance. This is a limited export smoke,
not all-shape/metric-provider/original-upstream parity. Tracer warnings were expected
for fixed shape; dynamic shape support is not claimed. ONNX is not selected by the
normal replay adapter yet. Export SHA256 is in the evidence JSON.

## J. Object sampling

Five strategies compared on 141 regions per candidate/size: central, eroded,
lower-center, near-surface percentile and bottom patch. All 141 eroded samples were
valid in each run, which does not prove accuracy. Median bottom-versus-eroded relative
differences were 11.45%/6.52% for relative 266/392 and 4.19%/3.10% for metric 266/392.
Keep eroded median as provisional generic policy; background/occlusion remain unresolved.
Default nearest sampling is bounded and vectorized; optional bilinear is deterministic.

## K. Detection association

Exact source/frame/timestamp/timing provenance equality required. Tests reject each
identity mismatch. Detector outputs remain original-camera boxes. No stale pairing.

## L. Track association

Public TrackSet only; observed box and timestamp, not predicted/filtered box. Compact
TrackDepthObservation does not change TrackId. The per-frame region estimate survives
an explicit ID replacement unchanged. Undetected wrong IDs remain a Task007 limitation.

## M. Stale/predicted semantics

Default EXACT_FRAME or UNAVAILABLE. Predicted-only and depth-unscheduled ticks never
receive fresh depth. No carried depth history or temporal smoothing is implemented.
Exact frame association is distinct from publication age; realtime result age is measured.

## N. Camera 3D point

Metric Z scales a normalized ray by Z/r.z; range scales by d. Analytical off-axis
tests demonstrate the distinction. Camera image/frame identity and dimensions are
checked. Estimated point retains calibration quality and UNKNOWN uncertainty.

## O. World transform

Typed supplied pose and world-point contracts use Guardian DevicePoseEstimate and
RigidTransform. Exact identity/device frame required. Missing pose/extrinsics returns
unavailable; no latest-pose substitution. No pose estimator is implemented.

## R. Temporal stability

confound these diagnostics. They are not distance error or static-scene stability.

## W. Cadence

Primary combined replay requested depth 2 Hz and detector 5 Hz over 600 source seconds.
Final published depth: 156 results, 0.26 per source second; 157 depth executions.
Alternate YOLOX run requested depth 5 Hz for 60 seconds and published 34 results
(0.57 per source second). Requested rates were not achieved. The 10-second freshness
limit is an explicit research configuration, not a production deadline.

## X. Latency

Final primary replay depth execution P50/P90/P95/P99: 880.71/1200.99/1311.05/4661.78 ms.
Sampling P50/P95/P99: 6.89/18.76/29.87 ms. Published depth age P50/P95/P99:
990.19/1474.41/3942.69 ms; maximum 5828.70 ms. These include desktop contention.
Initial 12-frame still comparisons had P95 around 3.39/9.78 seconds for relative
266/392 and 3.93/9.93 seconds for metric 266/392 under different overlapping load.
No controlled speed ranking or mobile claim is justified.

## Y. Memory/long run

Final replay: 18,001 decoded, 156 published, 17,845 dropped, zero failures, queue peak
one. Sampled process-tree RSS start/peak/end: 5,890,048 / 709,365,760 / 511,164,416 bytes.
Sampling begins before initialization, so start-to-end delta is not a leak measurement.
Two explicit tracking gap resets occurred. A 2,000-frame synthetic regression verifies

to extend catch-up only while backlog decreases, capped at 1,024 admissions. A slow
decoder still yields after 32 admissions. Batched region mapping removed per-pixel JNI
overhead. Both failed-throughput evidence and corrected measurements are preserved.
