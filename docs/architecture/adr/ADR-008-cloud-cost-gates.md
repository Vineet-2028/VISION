# ADR-008: Static hosting and zero default cloud budget

Status: accepted for the local Product V1.1 implementation.

## Context

Preserve the frozen Alpha engine while improving product usability and the private
data foundation. The supplied target architecture is a proposal, not evidence.

## Decision

Prepare static public output and an opt-in SDK export boundary, with no provisioning, SDK credential discovery, default upload or always-on GPU.

## Consequences and acceptance

Real cloud activation requires tenant authorization, aggregate quotas, retention/deletion integration, provider compatibility and an owner-approved budget.

See the Product V1.1 release checklist for executed verification and open gates.
