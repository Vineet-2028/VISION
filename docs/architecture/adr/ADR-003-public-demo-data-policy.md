# ADR-003: Publish explanations, keep raw media private

Status: accepted for the local Product V1.1 implementation.

## Context

Preserve the frozen Alpha engine while improving product usability and the private
data foundation. The supplied target architecture is a proposal, not evidence.

## Decision

Use two actual text-only Alpha outcomes and an explicitly illustrative scene. Gate raw replay behind Lab authentication and a separate media flag. Build public routes from an allowlist.

## Consequences and acceptance

No public footage rights are assumed. A consent-cleared short film can be added later without exposing the original benchmark.

See the Product V1.1 release checklist for executed verification and open gates.
